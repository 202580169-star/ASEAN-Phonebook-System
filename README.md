# ASEAN Phonebook System

A C# console application that manages student contact information for selected ASEAN countries using Object-Oriented Programming (OOP).

## Features
- Store student information.
- Edit existing student records.
- Search students by country.
- Display all students alphabetically by surname.
- Validate ASEAN country codes.

## Supported Country Codes

| Country | Code |
|---|---|
| Malaysia | 60 |
| Indonesia | 62 |
| Philippines | 63 |
| Singapore | 65 |
| Thailand | 66 |

## Requirements
- .NET SDK 10.0
- Visual Studio Code

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run:

```bash
dotnet run
```

5. Follow the instructions displayed in the console.

## Data Storage
Student records are stored in memory while the program is running. No database or text file is used.
